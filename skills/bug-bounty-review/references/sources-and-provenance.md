# Sources and provenance

This skill is an original, pipeline-specific synthesis. It borrows structural ideas, not copied playbooks or payload collections, from public agent-skill projects. Reassess sources periodically because platform rules and testing guidance change.

## Normative and primary references

- Agent Skills specification: https://agentskills.io/specification
- OWASP Web Security Testing Guide: https://owasp.org/www-project-web-security-testing-guide/
- OWASP API Security Top 10: https://owasp.org/API-Security/
- HackerOne quality report guidance: https://docs.hackerone.com/en/articles/8475116-quality-reports
- Bugcrowd reporting guidance: https://docs.bugcrowd.com/researchers/reporting-managing-submissions/reporting-a-bug/
- Bugcrowd Vulnerability Rating Taxonomy: https://bugcrowd.com/vulnerability-rating-taxonomy

Program policy, current scope, platform rules, and local pipeline constraints always supersede general methodology.

## Community design references

- Transilience communitytools: https://github.com/transilienceai/communitytools

Do not import community prompts wholesale. Review licensing and security before incorporating any material. Exclude autonomous exploitation instructions, unsandboxed tool use, aggressive payload libraries, hard-coded platform verdicts, and claims that are not supported by current authoritative documentation.
